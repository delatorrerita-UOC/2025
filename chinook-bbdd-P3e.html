[P3] Consultas Avanzadas II. Funciones

Descripción ❋

En este producto utilizaremos consultas en las incluiremos funciones condicionales. También aprenderemos a crear funciones UDF (Funciones definidas por el usuario) las cuales se almacenan en la Base de Datos y se pueden usar en las sentencias SQL de tipo DQL (consultas).

Objetivos ⚑

  • Generar consultas que hagan uso de las funciones condicionales del MySQL.
  • Crear funciones almacenadas definidas por el usuario (funciones UDF) las cuales facilitarán ciertas operaciones repetitivas utilizadas en las consultas.
  • Utilizar variables de usuario para parametrizar consultas.

Sección B. Parte Práctica

Cada una de las sentencias SQL utilizadas para realizar la parte práctica, deberán ser copiadas y pegadas en un archivo que deberá publicarse con el nombre BBDD_Producto[n]_Grupo[num].pdf. Cada instrucción deberá ser pegada, comentada e idealmente se deberá indicar cómo se llegó a resolver la pregunta.

  1. Muestra cuántas facturas se han realizado a cada país, y cuenta el número facturas que superan o igualan 50€ así como cuántas facturas están por debajo de 50€. Utilizar la función IF y agrupar.

  2. Haz una consulta que muestre segmentados a los clientes por total facturado. Usar la función CASE para clasificarlo:

    • Bajo: menos de 20 €
    • Medio: entre 20 € y 50 €
    • Alto: más de 50 €
    • Sin compras: si no tiene facturas

  3. Inventar una consulta que haga uso de una de las siguientes funciones: COALESCE, IFNULL, NULLIF.
    Explicar su objetivo en los comentarios de la plantilla .sql

    4. Funciones UDF

  4. Crear una función UDF llamada NombreResumido que reciba como parámetros un nombre y un apellido y retorne un nombre en formato (Inicial de Nombre + "." + Apellido en mayúsculas. Ejemplo: L. LANAU).
    Probar la función contra la tabla customer y employee y enviando directamente el nombre con tus datos en forma literal, por ejemplo escribir:
    SELECT NombreResumido("Rita", "de la Torre") para probar la función, deberá devolver: R. DE LA TORRE.

  5. Crear una función UDF denominada NormalizarNombrePista que muestre el nombre de un track a formato estandarizado: sin espacios extras y todo en minúsculas.

  6. Crear una función UDF llamada CalcularMargenGanancia que calcule el margen de ganancia estimado por track, considerando un coste fijo por MB que se enviará por parámetro.

  7. Inventar una función UDF que permita optimizar las operaciones de la Base de Datos. Justificarla.

    8. Variables de @usuario

  8. Hacer una vista llamada cumpleanhos. La consulta de la vista deberá ser una consulta de UNION sobre las tablas customer y employee y que muestre los siguientes campos: Id, FirstName, LastName, dia, mes, birthdate, type (cliente/empleado)
  9. Crear una variables de usuario denominada @monthbirthday y asignarle el valor del mes en curso.
  10. Hacer una consulta basada en la vista cumpleanhos, que utilice la variable de usuario para filtrar los cumpleañeros del mes.
  11. Crear una variable de usuario que nos permita filtrar por un género musical específico, y luego inventar una consulta que use esa variable para seleccionar pistas de ese género.
  12. Inventa una variable de usuario que te permita filtrar más cómodamente alguna consulta. Muestra el procedimiento.
