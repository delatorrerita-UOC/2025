[P5] Procedimientos Almacenados. Eventos.

Descripción ❋

En este producto desarrollaremos procedimientos almacenados utilizando las sentencias del lenguaje incorporado en MySQL:
Estructuras de Control, Tratamiento de excepciones y Cursores. Asimismo, aprenderemos a automatizar ciertos procesos mediante eventos.

Objetivos ⚑

  • Definir y utilizar procedimientos almacenados para automatizar tareas.
  • Programar tareas para que se ejecuten de forma periódica o en un momento en concreto,
    de tal manera que podamos automatizar ciertos procesos mediante eventos.

SECCIÓN B. PARTE PRÁCTICA

Cada una de las sentencias SQL utilizadas para realizar la parte práctica, deberán ser copiadas y pegadas en un archivo que deberá publicarse con el nombre BBDD_Producto[n]_Grupo[num].pdf. Cada instrucción deberá ser pegada, comentada e idealmente se deberá indicar cómo se llegó a resolver la pregunta.

  1. Crear manualmente (CREATE TABLE) una tabla denominada BonosRepresentantes. Agregar los siguientes campos:
    • EmployeeId: int
    • NombreRepresentante: varchar(100)
    • Mes: char(7)
    • TotalVentaClientes: decimal(10,2)
    • PorcentajeSobreMaximo: decimal(5,2)
    • BonoAsignado: decimal(10,2)
  2. Crear un procedimiento almacenado denominado GenerarBonosPorComparativa que realice lo siguiente:
    • Vaciar la tabla bonos_representantes.
    • Identificar cuál la mayor venta de un representante en el mes indicado (se recibirá por parámetro).
    • Seleccionar los representantes cuyos clientes hayan generado al menos el 75 % de esa venta máxima
    • Insertar estos representantes en la tabla BonosRepresentantes con el importe asignado.
    • El bono asignado será de 500€.
  3. Crear manualmente una tabla denominada ventas_mensuales. Agregar los siguientes campos:
    • Año: int
    • VentasEne: decimal(10,2)
    • VentasFeb: decimal(10,2)
    • VentasMar: decimal(10,2)
    • VentasAbr: decimal(10,2)
    • VentasMay: decimal(10,2)
    • VentasJun: decimal(10,2)
    • VentasJul: decimal(10,2)
    • VentasAgo: decimal(10,2)
    • VentasSep: decimal(10,2)
    • VentasOct: decimal(10,2)
    • VentasNov: decimal(10,2)
    • VentasDic: decimal(10,2)
  4. Crear un procedimiento almacenado denominado GenerarReporteVentasAnuales que realice lo siguiente:
    • Vaciar la tabla ventas_mensuales.
    • Llenar la tabla con las ventas del año que se envíe por parámetro.
    • Si el año no ha tenido ventas, indicarlo mediante un mensaje.
    • Si no se ha llegado a diciembre, colocar 0.00 como el total de venta de cada mes.
  5. Crear un evento que se ejecute el primer día de cada mes y ejecute automáticamente el procedimiento almacenado GenerarBonosPorComparativa.

  6. Inventar un procedimiento almacenado que permita optimizar las operaciones del sistema. Crear un evento periódico para ejecutarlo. Justificar su importancia.
