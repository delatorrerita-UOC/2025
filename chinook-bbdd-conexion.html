Hola gente:

Se os ha preparado un EndPoint en la nube para que puedan trabajar con una base de datos MySQL compartida en Amazon Web Services.

Para realizar la conexión con la Base de Datos, deberéis tener instalado el MySQL Workbench (ver anuncio: Preparación del Entorno de Trabajo ).

Iniciar la aplicación MySQL Workbench en vuestro equipo.

En el cuadro de diálogo Setup New Connection escribir las credenciales siguientes:

  • Connection Name:
  • Hostname: icx0p32.cu5so1xdpnd5.eu-west-1.rds.amazonaws.com
  • Port: 3306
  • Username:
  • Password:
  • Default Schema:

Hacer clic en Test conection para probar si todos los parámetros están configurados correctamente.

Hacer clic en Ok para guardar la conexión.

Para conectarse:

  • En la lista de conexiones de MySQL, hacer clic en el icono que corresponde a la conexión y esperar a que se establezca la conexión.

Se abrirá una nueva pestaña SQL con un editor en blanco en el que podréis escribir las consultas.
